# Public dashboard demonstration (3–5 minutes)

1. Open **Overview**. Read the checkout story before inspecting any implementation detail: the synthetic defect, India South impact, address-validation diagnosis, simulated rollback, and verified recovery.
2. Open **Detection**. Compare the 45.6% observed checkout conversion with the 91.4% baseline, then inspect why the source-bound detector was eligible to alert. Note that the known perturbation is applied to a metric copy.
3. In **Investigation**, compare the address-validation and payment hypotheses. The scripted provider proposed their evidence weights; deterministic software validated citations and calculated the displayed posterior.
4. Use **Evidence** to trace each cited change, flag transition, source, timestamp, and evidence ID.
5. Open **Impact** and distinguish directly counted exposure/failures from modeled churn and financial estimates.
6. In **Remediation & Recovery**, inspect the historical policy, approval requirement, simulated execution receipt, and recovery test outcomes. No button executes anything.
7. In **Evaluation**, first read the three-case fixture scope, then review calibration, coverage, abstention, and authority-violation measures.
8. Finish in **System & Limitations**. Confirm that this public result used committed scripted responses, the browser is static and read-only, and consequential truth remains outside model authority.
